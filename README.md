# Akort · Tune Up

Keman, bağlama, gitar: telleri kulağınla akort et

Doğru ses ile telin sesi birlikte çalar. Sesler yaklaştıkça dalgalanma (vuru) yavaşlar; kaybolunca akort tamamdır. Onayla'ya bas.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Müzik ve Ritim merkez uygulamasının oyunu; ortak motor: [muzik-motoru](https://github.com/taktemurr-ops/muzik-motoru).
